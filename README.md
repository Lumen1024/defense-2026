# defense

Лабораторные работы по криптографии: библиотека простейших криптографических
примитивов и консольное меню для их демонстрации.

## Состав

- `lib.py` — криптографическая библиотека:
  - `fast_pow_mod(a, x, p)` — быстрое возведение в степень по модулю;
  - `is_prime_fermat(n, rounds)` — вероятностный тест простоты Ферма;
  - `extended_euclid(a, b)` — обобщённый алгоритм Евклида (`a*x + b*y = НОД(a, b)`);
  - `discrete_log(a, y, p)` — дискретный логарифм («шаг младенца, шаг великана»);
  - `diffie_hellman(...)`, `diffie_hellman_get_public_key(...)`,
    `diffie_hellman_get_shared_secret(...)` — схема Диффи-Хеллмана.
- `gen.py` — генераторы параметров (числа, простые числа, задания для демо).
- `ui.py` — ввод/вывод: чтение целых чисел, выбор режима, обработка ошибок ввода.
- `main.py` — консольное меню с демонстрацией всех функций.
- `docs/labs.md` — условия лабораторных работ.

## Запуск

```bash
uv run main.py
```

или

```bash
python main.py
```

Требуется Python 3.14+.
