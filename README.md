# Лабораторные работы по криптографии

Учебный проект с реализациями базовых криптографических алгоритмов
на Python. Внешние зависимости не требуются.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `lib.py` | Общие алгоритмы: быстрое возведение в степень, тест Ферма, Евклид, дискретный логарифм, Диффи-Хеллман, хеширование и работа с файлами подписей |
| `gen.py` | Генераторы простых чисел, первообразных корней и параметров |
| `ui.py` | Ввод чисел, путей и очистка консоли |
| `main.py` | Демонстрации базовых алгоритмов (пункты 1–5) |
| `lab4.py` | Лабораторная работа №4 — шифрование файла с двумя ключами |
| `lab7.py` | Лабораторная работа №7 — схема Диффи-Хеллмана и шифр Вернама |
| `lab8.py` | Лабораторная работа №8 — электронная подпись RSA |
| `lab9.py` | Лабораторная работа №9 — электронная подпись Эль-Гамаля |
| `lab10.py` | Лабораторная работа №10 — электронная подпись ГОСТ Р 34.10-94 |

## Запуск

```bash
python3 main.py
python3 lab4.py
python3 lab7.py
python3 lab8.py
python3 lab9.py
python3 lab10.py
```

В лабораторных 8–10 подпись сохраняется в отдельный файл
`<имя_файла>.sig`. Используется хеш-функция SHA-256; каждый байт хеша
подписывается отдельно.
